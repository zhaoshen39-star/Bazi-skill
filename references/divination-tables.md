# 多术数层 · 资料表汇编（divination-tables）

> **用途**：为 bazi 技能的「多术数层」（称骨 / 小六壬 / 梅花易数 / 六爻纳甲 / 西洋星座 / 紫微斗数）提供**可直接编码**的数据表。
> **原则**：所有条目必须来自可查证来源，每条数据后标注来源 URL，整表给可信度。抓不到就写「未取得」，不凭记忆补数。
> **整理时间**：2026-10-29 ｜ **调研**：tables-researcher ｜ **范围**：仅资料，不含代码。
> **使用边界**：传统术数属民俗/文化模型，不是现代科学；输出只可表述为「传统术数口径下的倾向」，不得用于医疗、投资、法律等决策。

# 1. 袁天罡称骨算命（称骨歌）

## 1.1 口径与算法

- **算法**：出生**农历**年、月、日、时各有一个「骨重」，四者相加得总骨重（单位「两/钱」），再查对应歌诀。
- **输入口径**：
  - 年：按**年干支**（甲子年、乙丑年…）取重，60 年一循环（相差 60 年同重）。
  - 月：按农历月份（正月…十二月）。
  - 日：按农历日（初一…三十）。
  - 时：按十二时辰（子…亥，子时 23:00–01:00）。
- **来源**：「一个人出生的年份按年干支（即甲子年、乙丑年、丙寅年等）来确定重量……只要把年、月、日、时的重量加在一起，按照"称骨歌"一查，就可确定这个人一生的命运。」<https://www.163.com/dy/article/DGADJF5V0517TAE2.html>；「出生年的重量是以六十年为周期的（也就是说相差六十年的年份重量相同）」<https://www.daoisms.com.cn/2010/01/12/92122/>
- **可复算样例**（两源一致）：甲子年正月初一子时 = 1.2 + 0.6 + 0.5 + 1.6 = **3.9 两（三两九钱）**。<https://www.163.com/dy/article/DGADJF5V0517TAE2.html>；另例 1971（辛亥）年正月初一子时 = 1.7+0.6+0.5+1.6 = **4.4 两**。<https://www.daoisms.com.cn/2010/01/12/92122/>
- **编码注意（重要）**：
  1. 称骨按**农历年**取年重（民俗习惯以春节/正月初一换年），与八字「立春换年」口径不同；代码须显式传入农历年份或明确换算约定。
  2. 闰月：本轮未见明确原文规定；按农历月序取重是通行做法。【未取得】权威原文依据，建议代码注明「闰月按本月计」并在输出里标记低置信度。
  3. 子时流派（早/晚子时）在称骨中通常不分，23:00–00:59 一律算子时。

# 2. 小六壬（报时起课法 / 掌诀）

## 2.1 口径与算法

- **性质**：民间简易占法，「俗称报时起课法」；「占时按月、日、时顺序求之；得大安、速喜、小吉者为吉，其余为凶」<https://baike.so.com/doc/5406460-5644309.html>
- **三宫**：月宫、日宫、时宫；断课以**时宫为主**（月＝根、日＝苗、时＝果的通行说法，本轮来源多称「时宫为主体代表人物」）。
- **推算三步**（顺数、顺时针掐算，顺序永远固定：大安→留连→速喜→赤口→小吉→空亡）：
  1. 「以大安起正月」，顺数至生月，落点为**月宫**；
  2. 从月宫起初一，顺数至生日，落点为**日宫**；
  3. 从日宫起子时，顺数至生时，落点为**时宫**。
- **输入口径**：农历月（正月…十二月）、农历日（初一…三十）、十二时辰（子 23–01 … 亥 21–23）。<https://baike.so.com/doc/5406460-5644309.html>
- **验算样例**（来源同页，可作回归用例）：十一月 → 月宫小吉（1 大安、2 留连…11 小吉）；十一月初十 → 日宫留连（初一小吉、初二空亡、初三 大安…初十留连）。
- **编码注意**：只用「月、日、时辰」三个数字，不涉及年；农历闰月见 2.5。

## 3.3 时间起卦公式（可直接编码）

设：`Y` 年支序数（子1…亥12）、`M` 农历月、`D` 农历日、`H` 时支序数（子1…亥12）。

```
上卦数 = (Y + M + D) mod 8      // 余 0 作 8
下卦数 = (Y + M + D + H) mod 8  // 余 0 作 8
动爻   = (Y + M + D + H) mod 6  // 余 0 作 6
```

- 卦数 1–8 → 乾兑离震巽坎艮坤（先天数，见 3.2）；动爻 1–6 自下往上数（1 = 初爻，6 = 上爻）。
- **余 0 的取值**：卦取 8（坤）、爻取 6（上爻）。原文无余数时直接落「坤」「上爻」，见观梅占「（9+4+11）÷8 此处无余数…此卦为上卦坤…动爻为上爻」。<https://wapbaike.baidu.com/item/%E6%A2%85%E8%8A%B1%E6%98%93%E6%95%B0/779052>
- 原文表述：「以农历之年月日总和除以八，以余数为卦数求上卦；以年月日时总和除以八，以余数为卦数求下卦；再以年月日时总和除以六，以余数为动爻。」<https://m.sohu.com/a/120089427_435999/>

## 3.4 互卦 / 变卦 / 体用 规则

- **本卦**：上卦（外）+ 下卦（内）组成六爻。
- **互卦**：去掉初爻与上爻，取中间四爻：「以二、三、四爻为下卦，以三、四、五爻为上卦」。<https://wapbaike.baidu.com/item/%E4%BA%92%E5%8D%A6>
  - 「乾坤无互，互其变卦」：乾/坤两卦互后仍是乾坤，故《梅花易数》对纯乾纯坤改取其**变卦的互卦**（例：卜得乾卦、二爻动，则变卦上乾下离，互卦取上乾下巽）。
  - 互卦代表「测事时到应期这段时间的中段状态」。
- **变卦**：把**动爻**的阴阳反转，其余五爻不变（阳爻变阴、阴爻变阳）。变卦为「事之终应」。
- **体用**：
  - 「凡占卜成卦，即画成三重，本卦、互卦、变卦也。使于本卦分体用。」<https://www.daoisms.com.cn/2010/01/12/98722/>
  - 定位：**动爻所在之卦为用，另一卦（不动者）为体**。证：观梅占「右兑金为体，离火克之」——泽火革初爻动（下离），故下卦离为用、上卦兑为体；牡丹占「巽木为体，乾金克之」——天风姤五爻动（上乾），故乾为用、巽为体。<https://wapbaike.baidu.com/item/%E6%A2%85%E8%8A%B1%E6%98%93%E6%95%B0/779052>
  - 「体卦为主，用卦为事；互卦事之中间，刻应变卦为事之终应」；「体为己身之兆，用为应事之端」；互卦、变卦在断生克时「亦用也」（都当作「用」来与体论生克）。<https://www.daoisms.com.cn/2010/01/12/92162/>

## 3.5 体用生克断法要点（原文摘录）

《梅花易数·体用总诀》：

- 「体之卦气，宜盛不宜衰。」（盛衰见 3.2 卦气表）
- 「宜受他卦之生，不宜受他卦之克。」
- 「体宜受用卦之生，用宜见体卦之克。体盛则吉，体衰则凶。用克体固不宜，体生用亦非利。」
- 「体克用，诸事吉；用克体，诸事凶。体生用有耗失之患，用生体有进益之喜；体用比和，则百事顺遂。」
- 「体生用为之泄气」（如夏火逢土）。
- 「体党多而体势盛，用党多则体势衰。」（互、变与体同五行＝体党多）
- 吉凶次序：「用吉变凶者，先吉后凶；用凶变吉者，先凶后吉。」

# 4. 六爻纳甲（京房纳甲 / 火珠林体系）

# 5. 西洋十二星座（太阳星座）

## 5.1 口径

- **太阳星座** = 太阳视黄经落入黄道 30° 区间，即占星学的「太阳过宫」。占星用**回归黄道**（tropical zodiac）：春分点固定为白羊宫 0°，各宫按黄经每 30° 等分，与地球实际星空位置无关。
- 十二宫宫名沿用同名天文星座，但「宫」是等分刻度、与星座实际天区不是一回事（宫名对照见 5.2、中气对照见 5.3）。
- 占星日期区间是**传统约定**，不是天文观测边界；精确判定应算出生时刻的太阳视黄经（见 5.5）。
- 天文黄道实际穿越 **13 个星座**（含蛇夫座）——占星十二宫不含蛇夫座，见 5.6。

## 5.4 交界日处理（重要）

1. **交界日不能只看日期**：太阳每年进入某宫的瞬间不同（闰年、岁差章动、时区），因此生日落在区间端点的人，须按**出生时刻**换算太阳视黄经后再判星座。
2. **各源 ±1 天**：同一星座的起止日在不同渠道常差一天（如天蝎 10/23 或 10/24 起）。本表取「黄道十二星座」词条表格版；编码时把日期表当**展示/兜底**用，不要当精确判定。
3. **推荐判定流程**：公历日期+时刻 → UTC/儒略日 → 太阳视黄经 λ → `floor(λ/30)` 映射为宫序（0=白羊）。λ 可用低精度公式（精度约 0.01°）或天文库（如 `pyswisseph`、`skyfield`、`astropy`）。
4. **【未取得】**逐年「太阳入宫时刻表」；本轮未抓取权威星历表。若需要严格输出，请用天文库现算，或接万年历数据。
5. **时区**：出生时刻须先换算为同一参考系（建议 UTC），不能拿当地「几点」直接取模。

## 5.5 回归黄道、恒星黄道与岁差

- **回归黄道**（西洋占星）：以春分点为 0°，宫与季节绑定；「白羊宫 = 3月21日前后」因此大致稳定。
- **恒星黄道**（印度占星/吠陀）：以固定恒星（娄宿）为起点，宫与季节脱钩；因岁差（约 72 年差 1°），两套黄道现相差约 24°（近一宫），同一时刻算出的星座常差一个宫。
- **岁差**：春分点沿黄道缓慢西移，现已从白羊座退入双鱼座天区；所以「天文上太阳所在的星座」与「占星太阳星座」并不一致（例如占星白羊座的人，天文上太阳多半在双鱼/白羊天区之间）。
- 编码：若做跨体系对照，必须显式标注 zodiac 体系（`tropical` / `sidereal`）与 ayanamsa 参数；本文日期表一律按 `tropical`。

## 5.6 天文第十三星座：蛇夫座

- 天文黄道穿越 **13 个星座**，含**蛇夫座**（Ophiuchus）。太阳每年约 **11月30日—12月18日** 位于蛇夫座天区。
- 占星十二宫体系**不设蛇夫座**：十二宫是从春分点等分的 30° 刻度，不是按天区大小划分；蛇夫座对应黄经约 240°–270° 的一段（与人马宫重叠），故占星上仍归人马宫。
- 本表**不提供蛇夫座日期**作为太阳星座选项；此项仅作为「占星 vs 天文」差异说明与输出免责声明。
