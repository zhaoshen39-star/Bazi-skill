# 解读框架与表达边界

排盘之后按这里给的顺序解读。核心原则：**先结构、后倾向、再建议；可解释、可质疑、不宿命**。

## 1. 解读顺序

```
核盘 → 旺衰 → 格局 → 喜用 → 十神结构 → 大运流年 → 神煞辅参 → 建议与不确定性
```

跳过前面直接说「你今年会怎样」，是最常见的错误。

## 2. 十神象义

十神是**功能与关系**的符号，不是具体事件。以下给核心象与偏旺/受制的常见表现：

| 十神 | 核心象 | 偏旺常见表现 | 偏弱/受制常见表现 |
|---|---|---|---|
| 比肩 | 自我、独立、同辈、竞争 | 自我强、好胜、朋友多、开销大 | 主见不足、易随同辈 |
| 劫财 | 行动、胆识、合作与竞争、花费 | 冲动冒险、合伙纠纷、破财 | 执行力弱、不敢争取 |
| 食神 | 才艺、口福、温和、创造力 | 安逸享受、行动力需财星引动 | 表达平淡、福气感弱 |
| 伤官 | 才华、表达、创新、批判 | 傲气口舌、不服管、感情多变 | 才华难显、压抑 |
| 正财 | 稳定收入、务实、责任（男命妻星） | 精打细算、偏保守 | 理财不稳、收入波动 |
| 偏财 | 流动财、经营、社交（男命父/异性缘） | 豪爽投机、桃花多 | 不善经营、财来财去 |
| 正官 | 秩序、地位、责任、约束（女命夫星） | 保守、压力大、守规矩 | 缺约束、不喜管束 |
| 七杀 | 魄力、压力、竞争、权威 | 霸道或压力大、易冲突 | 缺魄力、抗压差 |
| 正印 | 学识、庇护、名誉、母亲 | 依赖、懒散、想多做少 | 少庇护、学习支持不足 |
| 偏印 | 偏门学问、技艺、直觉、孤独 | 孤僻多疑、偏执 | 技艺不专、兴趣分散 |

用法：找**最旺的十神**（月令、透干、成局者）→ 它是命局的主要「声音」；再看被克被制的十神 → 它代表被压抑的领域。

## 3. 旺衰

脚本用**结构力模型**给出 ratio 与标签（身强/偏强/中和/偏弱/身弱），再用「三得」复核：

- **得令**：月令五行生扶日主（同我=旺，生我=相）；失令则休/囚/死。月支权重最高（0.40）。
- **得地**：地支藏干中出现比劫或印（日主有根）。根在月日支最有力量；本气根 > 中气根 > 余气根；被冲刑合害的根标 `damaged`。
- **得势**：非日柱天干中比劫、印星多（≥2 个）。

判定：三得者身旺；三失者身弱；两得一身弱者偏强，一得一失者中和。

- **身强/偏强**：喜克（官杀）、泄（食伤）、耗（财）；忌再生扶（印比）。
- **身弱/偏弱**：喜生扶（印、比劫）；忌克泄耗过重。
- **中和**：以调候与格局流通为主。

读脚本结论时注意：`score` 靠近分界线（0.27/0.35/0.45/0.57）时脚本给低置信度，此时应写「介于身弱与偏弱之间」这类措辞，不要硬贴一档；`structure_notes` 与 `de_di_detail.damaged` 说明刑冲合折损，一定要在解释里交代。

**特殊格局**：v3 会自动识别「从弱（从财/从杀/从儿）」与「从强（专旺）」候选（`special.type/kind/reasons`）：前者要求无本气根、无印比透干且同党占比 ≤0.20；后者要求无官杀透、官杀≤6%、财≤10% 且占比 ≥0.80。命中的命盘按「顺其旺神」论，不套常规扶抑；不确定时不要轻率定性。

## 4. 格局

v3 按子平真诠取格：**月令本气→中气→余气，取第一个透干（年/月/时干）的藏干十神为格；皆不透取月令本气**；月令为禄/刃则单列建禄格/月劫格（阳刃格）。取完再判顺逆用、相神、成败与救应：

| 格 | 取法 | 成格倾向（相神） | 破格/忌讳 |
|---|---|---|---|
| 正官格 | 月令本气/中余气透干的官星 | 官印相生、财官相生 | 伤官见官、官杀混杂、刑冲 |
| 七杀格 | 同上，杀星 | 食神制杀、杀印相生 | 杀重无制、财党杀 |
| 正财/偏财格 | 同上，财星 | 食伤生财、官杀护财 | 比劫夺财、财多身弱 |
| 食神格 | 同上，食神 | 食神生财、身旺食秀 | 枭神夺食、身弱食重 |
| 伤官格 | 同上，伤官 | 伤官配印、伤官生财 | 伤官见官、伤官无制 |
| 正印/偏印格 | 同上，印星 | 官杀生印、印绶护身 | 财星破印、偏印夺食 |
| 建禄格 | 月令为日主临官（禄） | 有官杀或食伤财立格 | 比劫无制、争财 |
| 月劫格（阳刃格） | 月令为日主帝旺/劫财 | 官杀制刃 | 无制、刃旺夺财 |
| 杂气格 | 辰戌丑未月 | 透干取用（一透一用、兼透兼用） | 不透干、刑冲 |

脚本会输出 `status`（成格 / 成中有败 / 败中有救 / 破格 / 待定 / 特殊格），并列出 good（成格条件命中）、bad（破格因素）、rescue（救应）与 `month_damage`（月令受冲刑合害）。**解读时先说 status 与依据，再说倾向**；broken 格局不等于命差，说清「病在哪、药在哪」。

注意：格局是「结构判断」，不是「身份预测」。同一个正官格，可以对应公务员、企业中层、也可对应自律型自由职业者。

## 5. 喜用与调候

四法各出一票，冲突时要说明取舍（脚本的 `arbitration` 会写仲裁规则与冲突）：

1. **扶抑**：身弱用印比，身强用财官食伤。
2. **调候**：按《穷通宝鉴》120 格表（日干 × 月支）取首选/辅佐天干——冬水寒用火暖、夏火炎用水润只是其中最常见的一类；寒暖指数（月令基准 + 火水差占比）只用来定「急需 / 需要 / 不急」。调候是「急症」，标急需时优先于扶抑。
3. **通关**：两神相战时取中间者：
   - 食伤与官杀战 → 用财通关（食伤生财、财生官杀）；
   - 财与印战 → 用官杀通关（财生官杀、官杀生印）；
   - 比劫与财战 → 用食伤通关（比劫生食伤、食伤生财）；
   - 官杀与比劫战 → 用印通关（官杀生印、印生身）。
4. **病药**：找最伤命局的一处（比劫争财、财多身弱、印重气滞、食伤泄身、官杀攻身、寒暖失衡、刑冲过多），再开对应药神。

仲裁序：**特殊格 > 破格救应 > 调候急需 > 病药 > 扶抑**。输出喜用时还要看**用神是否有力**（透干且有根 / 有透无根 / 有根无透 / 虚浮无根）：用神虚浮则效力打折，要写进结论。同时说明喜用五行对应的大运/流年何时到位。

## 6. 大运与流年

- **大运管十年**：地支是承载力（这十年「底盘」），天干是外显（社会角色与事件类型）。
- **流年管一年**：天干看外显主题，地支看根基与引动。
- **交运**：起运时刻后每十年交一步；交运前后一两年常有调整感，不要过度解读。
- **岁运并临**：流年干支与大运相同，主题被放大或反复。
- **伏吟/反吟**：大运或流年与月柱相同（伏吟）或天克地冲（反吟），主「重复/变动」，不是「大凶」。
- **引动**：流年冲、合到命局某柱 → 该柱代表的人事被引动（年柱长辈/环境、月柱父母兄弟/事业、日柱自身配偶、时柱子女晚年）。
- **十神主题**：流年见官杀 → 工作、压力、名分；见财 → 钱财、男命感情；见印 → 学习、文书、长辈；见食伤 → 表达、变动、子女；见比劫 → 同辈、竞争、花费。
- **综合喜忌（v3）**：脚本给大运/流年算两层——**基调分**（用神×2.2、喜神×1.3、忌神×-1.9、仇神×-1.0 的五行角色加权）＋**引动分**（与命局/大运的合冲刑害、伏吟、反吟、半合、岁运并临）。大运＝基调×0.55＋引动、流年＝基调×0.5＋引动，截断 [-4,4]；同时给 `themes` 领域、`confidence` 置信度与 `yingqi` 应期提示。基调定方向、引动定「哪年因何动」，仍然不是事件预测；同一结果基调与引动相反时，脚本会降低置信度。

硬性要求：**不许只看流年不看大运**；**不许用单一年份断吉凶**。

## 7. 分领域解读

| 领域 | 主要依据 | 提醒 |
|---|---|---|
| 性格 | 日主 + 月令 + 最旺十神 | 描述倾向，不断言「必然如此」 |
| 事业 | 官杀、印、食伤、财的组合与喜用 | 行业五行对应是传统类比，不是职业测评 |
| 财运 | 财星、食伤（财源）、比劫（分财）、大运 | 不预测具体金额、不推荐投资标的 |
| 感情 | 男看财星、女看官杀；日支=配偶宫；合冲 | 不用「孤克」「二婚」等断语；描述互动模式 |
| 学业 | 印星、食伤、文昌 | 只给学习方式与方向倾向 |
| 健康 | 五行偏枯与传统脏腑对应 | **不能替代就医**；只谈作息与养生倾向 |

五行—行业/脏腑只是**传统对应**，用于帮助用户反思，不可当作事实断言。

| 组合 | 结构 | 传统解读（倾向） |
|---|---|---|
| 官印相生 | 官生印、印生身 | 稳定、有靠山、适合体制/专业路径 |

| 伤官配印 | 印制约伤官 | 才华有边界，适合技术、学术、创作 |
| 食伤生财 | 食伤生财星 | 靠技能、表达、产品赚钱 |

| 枭神夺食 | 偏印克食神 | 思路受限或福气受阻，需财制枭 |
| 财官相生 | 财生官 | 资源与责任相连；官杀混杂时先清格 |
| 官杀混杂 | 正官与七杀同见 | 规则/压力互相牵扯，需去杀留官或合制 |

这些是「结构—倾向」的对应，不是判决书。写答复时给「倾向 + 触发条件 + 可调整做法」。

## 9. 表达模板

```
盘面：……
旺衰：日主 X，生于 X 月（得令/失令），综合偏X；依据：……
格局：X 格，透干 X，注意 X。
喜用：喜 X、忌 X；理由（扶抑/调候/通关）：……
结构：最旺十神 X，组合 X（如官印相生）；可能表现为……
运势：当前大运 X（喜/忌），近三年流年 X、X、X，主题偏向……
建议：可执行的三条（作息/学习/职业方向/沟通方式）
不确定性：出生时间/流派/节气边界/术数非科学性
```

措辞规则：

- 用「倾向」「较容易」「在……方面更有优势」「若……则……」。
- 不用「注定」「必然」「一定会」「大凶」「克夫/克妻」「短命」等。
- 不制造恐惧，不推销付费改运、法事、吉祥物。
- 用户若问具体投资、疾病、诉讼结果：说明八字不做此类判断，给通用建议并建议咨询专业人士。

## 10. 通俗版表达（默认先给这个）

脚本已实现：`bazi.py --plain-only`（文本）/ `--json --plain`（`plain` 字段），规则在 `scripts/plain.py`。手写答复时按同一结构：

```
一句话 → 你是个什么样的人 → 你的长处 → 容易卡住的地方 → 钱和工作 → 感情
      → 身体 → 现在走到哪 → 接下来几年怎么走 → 给你三条建议 → 名词翻译 → 说明
```

### 10.1 术语翻译表（正文一律用右列）

| 术语 | 说人话 |
|---|---|
| 日主 / 日干 | 你自己（出生那天的天干） |
| 身强 / 身弱 | 底子能不能扛事：能扛 / 容易累、要借力 |
| 用神 / 喜神 | 最需要的力量 / 顺带帮忙的力量 |
| 忌神 / 仇神 | 容易添乱的力量 / 帮凶 |
| 比劫 | 同辈、伙伴、自立 |
| 印星 | 学习、证书、长辈与平台 |
| 食伤 | 表达、点子、创造 |
| 财星 | 现实的钱与资源 |
| 官杀 | 压力、责任、规则 |
| 大运 | 十年一段的大环境 |
| 流年 | 一年的节奏，看今年该进还是该守 |
| 格局 | 你天生适合走的那条路、靠什么吃饭 |
| 调候 | 太热要水、太冷要火：先补最缺的那股气 |
| 神煞 / 纳音 / 伏吟 / 反吟 | 只作辅参，通俗版不展开 |

### 10.2 数字与分数

- 不写内部评分、占比、权重；强弱只说「底子薄 / 均衡 / 能扛」。
- 需要体现程度时用「偏吃力 / 比较顺 / 平稳」这类词，不用 ±3.1 这类分数。

### 10.3 预测句型（通俗版）

每条一年 2–3 句，三件套：

1. **感觉/主题**：「今年主题是钱和责任；还会被某件事牵住。」
2. **怎么用**：「适合守：把账理清、把人脉和身体顾好，大动作留到下半年。」
3. **避开**：「忌冲动投资、替人担保、硬换赛道。」

规则：不写「必然/一定/注定」，不报具体事件（结婚、升职、破财金额），不下健康诊断；置信度翻成「比较确定 / 中等把握 / 不太好说」。

### 10.4 长度与取舍

- 正文 800–1500 字；性格/长处/短板各 3–5 条。
- 通俗版可以省推导过程，不能省不确定性；结尾保留「不是命定、时间不准会变、不替代专业意见」三条。

## 11. 专题推测（八域）

脚本 `--topics` 把同一份分析按八个生活领域重组，输出可直接对用户讲。规则：**结构定倾向，引动定应期**，不新增预测源（年份来自 `chart.liunian[].timing`）。

| 域 | 主依据 | 判读要点 | 禁区 |
|---|---|---|---|
| 婚恋 | 男看财星/女看官杀、日支（夫妻宫）合冲、桃花红鸾天喜 | 星弱→靠经营；宫受冲→聚少离多/节奏反复；财星年、夫妻宫被合冲年为「有动静」年 | 不断「孤克/二婚/必嫁」，不指认具体对象 |
| 事业 | 五党占比 → 路径（官杀=组织/责任，食伤=技术/创意，财=经营/成交，印=专业/资格）、格局成败、相神 | 官印相生宜平台型；身弱先借平台；换工作挑印/官引动年 | 不预测升职时间与职位 |
| 财富 | 财星强弱、食伤生财、比劫夺财、官杀护财、财库（按财星五行取库：木未/火戌/金丑/水辰） | 身弱财重=看得见留不住，重现金流与平台；比劫旺忌担保/合伙不分账 | 不承诺收益、不指投资标的 |
| 学业 | 印星、官杀（考试）、财星干扰 | 印重宜系统学历/证书；印弱宜短周期实用技能；财压印需固定学习时段 | 不承诺考运与结果 |
| 健康 | 五行偏枯（最弱/最旺）、调候寒暖、日支受冲年 | 最弱五行→对应脏腑长期养护；最旺→过用先报警；只谈作息 | **不作诊断**，明确「不能替代就医」 |
| 六亲 | 年柱（祖辈/根基）、月柱（父母/兄弟）、时柱（子女/晚辈）宫位合冲、男女命子女星不同（男食伤/女官杀） | 宫位受冲→聚少离多；子女星弱→缘分靠经营 | 不断父母寿数、不断子女个数 |
| 迁移 | 驿马（三合局之马是否入命）、四马之地占比、年支/时支引动、用神方位 | 驿马入命+四马多→动象强；迁移看驿马/冲合年时支的年份 | 不给「必须出国」类断言；方位只作参考 |
| 人际 | 天乙/天德等贵人星、劫煞等耗损星、官杀（上级压力）、比劫（同辈竞争） | 贵人只在「先动起来」时出现；官杀旺年防上级压力 | 不断「犯小人」具体到人 |

写法：

- 只回答用户问的域；先说结论与年份，再挑 1–2 条依据解释。
- 「有利年份」里被标「动而不顺」的年份，要老实说「有动静但基调不利，宜谨慎」，不要美化成机会。
- 每域结尾给 2–4 条能落地的建议；置信度低时明说「信号偏少，只作参考」。

## 12. 多术数层（其它命理体系，并列参考）

脚本 `--divination` 在八字之外另跑几套**独立**的模型，并汇总「多体系交叉参考」。它们不是同一结论的多次验证，只代表不同侧面。

| 体系 | 起法/算法 | 输出 | 读法 | 禁区 |
|---|---|---|---|---|
| 小六壬 | 农历月从大安起顺数、日从此宫起初一、时从此宫起子时；六宫 大安/留连/速喜/赤口/小吉/空亡 | 落宫、吉凶、五行方位、断辞、白话 | 多用于「当下问事」：速喜偏快、大安偏稳、留连偏拖、赤口防口舌、空亡防落空 | 不当长期格局用；同一问题不反复起卦 |

交叉参考的写法：

- 先说清「这是几套不同模型，不是互相验证」。一致时写「几种说法倾向一致」，不能写「因此必然如此」。
- 不一致时如实并列：「八字看…，梅花卦看…，两说角度不同」——不要挑顺耳的说，也不要拿一套去否定另一套。
- 小六壬、六爻属「问事」取象，只代表起卦那一刻；称骨、星座、生肖属民俗/流行占法，只能说「文化参考」。
- 不因为多体系「都说不顺」加重恐吓，也不因为「都说顺」承诺结果。

## 13. 跨体系融合（`--fusion`：西洋/印度占星、数字学、紫微与八字并看）

融合层（`scripts/fusion.py`）把六类体系（八字、紫微、西洋占星、印度占星、数字学、民俗占法）各自的结构映射到 9 个生活领域（性格/事业/财富/感情/健康/家庭/迁移/学业/人际），按信息量权重聚合成一个方向信号与共识标签。它**不新增断语、不预测事件、不输出概率**，只回答「这些体系在哪些领域同向、哪些领域有张力」。

读法（按顺序）：

1. **看体系可用性**：`systems[].available`。缺的体系（文件缺失/输入不足）标「证据不足」，**不得当 0 分或当反向信号**，也不要拿它去凑「多数」。
2. **看九域**：`level` 是方向等级（明显偏顺…吃力），`consensus` 是体系间一致程度，`votes` 是逐体系票与一句依据。先讲「偏顺/吃力的领域」，再讲依据。
3. **看张力**：`tensions[].detail` 列出同域里方向相反的体系与数值。张力不是「谁对谁错」，而是**该领域信息不足或模型不同**；如实并列，不硬圆成一条结论。
4. **看时机**：`timing` 把八字大运流年（基调/引动分）、紫微大限、数字学个人年、民俗落宫聚合成当年方向；它描述「当前周期顺逆」，不指向具体事件。
5. **看整体**：`overall.agreement` 是各域平均一致度，`overall.confidence` 只是「材料是否互相支持」的把握，**不是预测准确率**。

共识标签的含义：

| 标签 | 含义 | 写法 |
|---|---|---|
| 一致 | 各体系方向相同、加权一致度高（≥0.75） | 「几种体系在这点上倾向一致」 |
| 多数 | 多数体系同向（0.55–0.75） | 「多数说法偏…，另有不同声音」 |
| 分歧 | 同向权重不过半 | 「体系间说法不一，这一域信息不足」 |
| 对立 | 反向体系权重占优 | 「明确对立，不宜单取一边」 |
| 单体系参考 | 只有 1 个体系出票 | 「仅供参考，不作结论」 |
| 信号相抵 | 有票但方向互相抵消 | 「读作中平，别过度解读」 |
| 证据不足 | 没有任何体系在该域出票 | 「这一域没有可用的材料」 |

必须遵守的边界：

- **权重 ≠ 效度**：八字 1.0 / 紫微 0.9 / 西洋 0.9 / 印度 0.7 / 数字学 0.5 / 民俗 0.4 是「信息量与可核对程度」排序，八字权重高不代表八字更「科学正确」。
- **同源不等于独立**：西洋与印度占星共享星历与黄道（只差岁差），八字/紫微/民俗共享干支历法与阴阳五行，相关来自同源；一致只是**材料互相支持**，不是两次独立验证。
- **计算精度 ≠ 预测效度**：占星盘能算到角秒级只证明天文计算正确；Carlson 1985 双盲等证据表明占星预测效度阴性（见 `fusion-systems.md` §2）。
- 数字学、称骨、星座、小六壬属现代民俗/流行占法，只当文化参考与自省提示；不得据此劝人放弃就医、维权或重大决策。
- 不因「多体系都说差」加重恐吓，也不因「都说好」承诺结果；缺体系时如实写「证据不足」，不用「中性」冒充「无信号」。

## 14. 伦理与免责（写进每次答复的结尾）

- 八字属中国传统术数与民俗文化，**不是科学**；其「准确性」只在历法计算层面成立，命理解读属解释框架。
- 人的选择、环境、教育、努力与偶然性，远大于任何命理模型。
- 不用于医疗诊断、法律判断、投资决策；不因命理结果让用户放弃就医、维权或正常生活规划。
- 尊重用户信仰：可以按要求做传统解读，但保持诚实——计算是精确的，解释是文化的。
