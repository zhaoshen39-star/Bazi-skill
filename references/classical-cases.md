# 古典命例对照集（task-8）

> 用途：把古典文献中**原文写明了结论**的命例固化为可回归的对照集，用 `scripts/analysis_v3.py`
> 的 `pattern()` / `yong_shen()` 逐例复算，测量「古法结论 ↔ 现行引擎输出」的一致与差异。
> 配套文件：`tests/fixtures_cases.json`（结构化命例，64 例）、`tests/verify_cases.py`（对照脚本）。
>
> **本文件不评估、不宣称任何「准确率」。** 统计的是「与古典文本断语的一致率」，不是预测命中率；
> 古典断语本身多为个案记述，存在幸存者偏差，不能作为统计效度证据。

## 0. 口径与边界

### 0.1 取例标准

1. 命例必须出自**古典原文**（本文用《子平真诠》清·沈孝瞻，常先·易古籍书库录文）；
2. 原文必须给出**四柱**，并写明**格/成败/用神**之类的可对照结论；
3. 只收四柱齐全者；原文只给贵贱评语（如「大贵」「丞相命」）者按「成格」记，但若原文没有明确的成败语境则 `status_hint=null` 不参与成败断言；
4. 录文有 OCR 讹字（壬/王、己巳/己己、癸巳/癸己、壬子/王子）时按干支合法性校正，并在 `note` 中注明；
5. 3 例属「变格」（原文明确说明格局已变），按**变后之格**记录，并在 `note` 标注。

### 0.2 断言口径（verify_cases.py 只比这些字段）

| 字段 | 古法期望 | 与 v3 的对照方式 | 说明 |
|---|---|---|---|
| `pattern` | 古法八格名（财格/印格/阳刃格为类名） | 归一化后**精确相等**：财格≙正财格或偏财格、印格≙正印格或偏印格、阳刃格≙月劫格（阳刃格） | 类名只用于吸收古法八格与 v3 十格的命名差，不改变取格结果 |
| `shun_ni` | 顺用/逆用 | v3 值**前缀匹配**（`逆用（…）` 视作「逆用」） | 顺逆属性由 v3 的格名决定 |
| `status_hint` | 成格/成中有败/败中有救/破格 | **精确相等** | 只对原文有成败断语的 61 例断言 |
| `yong_shen_elements` | 原文明确「用官杀/用财/用印/用食伤」换算的五行 | v3 `primary_elements` **包含**该五行 | 仅 5 例「刃用官杀」命例；古法「用神=格神」与 v3「喜用五行」不是同一概念，见 §4-E |

### 0.3 不可比边界（重要）

- 古法「用神」= 月令所取的**格神（十神）**，顺逆与相神皆围绕它；
- v3 `yong_shen()` = **扶抑/调候/通关/病药**四法合参后给出的**喜用五行**；
- 两者只在「身强喜官杀、身弱喜印比」这类扶抑基线上近似，不能把古法「用财」「用印」直接当五行断言。
  因此本对照**只对 5 例原文明确「刃用官杀」的命例**断言 `yong_shen_elements`，其余命例的喜用差异只在 §4-E 定性讨论。

## 4. 差异归因

### A. 取格口径差异：月令本气 vs 透干（7 例 pattern 不一致）

古法（《子平真诠·论用神》）「八字用神，专求月令」——月令**本气**即格神，透干只是取用与相神的条件；
v3 现行顺序是「月令本气透 → 中气透 → 余气透 → 皆不透取本气」，即**透干优先于本气**。两者在下列命例分道：

| 命例 | 月令藏干与透干 | 古法 | v3 |
|---|---|---|---|
| `zhengguan-xue` 薛相公 | 申藏庚壬戊，庚官不透、壬印透（月干/时干） | 正官格（财印为相） | 正印格（中气透干） |
| `zhengguan-zaqi` 杂气正官 | 未藏己丁乙，己官不透、丁印透 | 正官格（杂气正官，乙官透干会支） | 正印格（中气透干） |
| `cai-wangxueshi` 汪学士 | 未藏己丁乙皆不透 | 财格（财用伤官化劫） | 偏印格（本气己） |
| `yin-ma` 马参政 | 申藏庚壬戊，壬比肩透（年/月/时三壬） | 印格（用偏官） | 建禄格（比肩透干归禄刃） |
| `sha-tuo` 脱丞相 | 辰藏戊乙癸，戊食神透；古法以「辰中暗煞壬透之」 | 七杀格 | 食神格（本气透干） |
| `sha-liu` 刘运使 | 亥藏壬甲，甲偏印透（年干） | 七杀格（身重煞轻借财清格） | 偏印格（中气透干） |
| `sha-yue` 岳统制 | 巳藏丙戊庚，庚比肩透（时干） | 七杀格（去官留煞） | 建禄格（余气透干） |

**归因结论**：
1. v3 对「中气/余气透干」的取格权重偏高，且**不区分本气是否当令得势**——古法在月令本气为格神时，即使本气不透也以本气定格（如薛相公、杂气正官），透出的中气只作相神；
2. v3 把「比肩/劫财透干」一律归入建禄/月劫格，口径过宽：古法建禄仅指**月令为日主禄位**（或月劫为羊刃位），比肩透干不等于建禄（马参政、岳统制因此错位）；
3. 「透干」必须是**月令藏干**透出；`sha-tuo` 的壬不在辰藏之中，v3 以辰中本气戊取格，而古法以「暗煞透干」另论——属 v3 规则未覆盖的取格路径（月令藏干外透干参与取格的条件）。

### B. 成败判定过严（54/61 例不一致的主因）

v3 在 61 例有成败断语的命例中只输出 7 例「成格」，其余 31 例「成中有败」、15 例「败中有救」、6 例「破格」、2 例「待定」。
机制上（`analysis_v3.py` `GOOD_BAD_RULES` + status 聚合）：

1. **破格因素门槛偏低**：如正官格「官逢伤尅刑冲」、财格「财轻比重」等在 v3 中以 `_god_rank`（透干=3/月令本气=2/其他本气=1/仅藏支=0/-1）判定，许多命例中同现的忌神（如印格之财、食神格之枭）rank 达到门槛即记为败项；
2. **ratio 阈值附加败项**：正官格 `ratio≤0.39` 加败项、七杀/伤官/食神格 `ratio≤0.37` 加败项——古典命例中「身弱而贵」的贵格（如 `shang-cai` 蔡贵妃、`sha-yiwei`）因此被判「成中有败/败中有救」；
3. **`month_damage`（月令被刑冲合害）一律加败项**：三合、六合等「合」也计入月令受损，而古法「会合可解刑冲」、合局常成格条件（如 `shi-liang`、`lu-muhuo`、`lu-jinshui` 均因此降级）；
4. **good/bad 聚合语义**：古法「成中有败」是**格中带忌**（仍以成格为主、层次有损），v3 把 bad 视为与 good 并列的状态，导致「成格」几乎不出现。

**归因结论**：v3 的成败模块需要「成格为主、败为减损」的校准，而不是把任一败项升格为 status；月令三合/六合不应等同刑冲；ratio 阈值应只用于「扶抑是否得力」而非直接判败（详见 §5 建议 1、2）。

### C. 偏印（枭）顺逆的流派分歧（5 例 `shun_ni` 不一致）

| 命例 | 月令本气 | 古法（论印绶章） | v3 |
|---|---|---|---|
| `yin-linhuaihou` | 卯中乙（偏印） | 印格·顺用 | 偏印格·逆用 |
| `yin-maoyin` | 酉中辛（偏印） | 印格·顺用 | 偏印格·逆用 |
| `yin-wang` | 申中庚（偏印） | 印格·顺用 | 偏印格·逆用 |
| `yin-niu` | 酉中辛（偏印） | 印格·顺用 | 偏印格·逆用 |
| `cai-wangxueshi` | 未中己（偏印） | 财格·顺用 | 偏印格·逆用 |

《子平真诠·论用神》底本作「**煞伤劫刃**，此用神之不善而逆用之者也」，旧电子版作「杀伤**枭**刃」——
枭（偏印）是否属逆用，两个版本即有分歧；《论印绶》章则把正偏印命例一律作「印绶」论。
v3 采用「偏印格=逆用」的旧版口径。**这不是实现 bug，而是版本/流派选择**，建议在文档与配置中显式声明
（若采用底本口径，`SHUN_NI` 中偏印格应改为顺用；两者不可同时成立）。

### D. 特殊格（从格）判定门槛（3 例）

`shi-gong`（甲午 丁卯 癸丑 丙辰）、`shi-hu`（戊戌 壬戌 丙子 戊戌）、`shi-liu`（癸酉 辛酉 己卯 乙亥）
古法均作**食神格**（带煞/带印/生财），v3 判为「特殊格（从儿格）」（status 以「特殊格」开头，不参与断言）。
说明 v3 从格判定（`special_hints`/从格分支）阈值偏低，食伤旺而无财的食神格容易被误判从儿；
建议从格判定要求「无印无官杀、日主无根」等更强条件，并在 pattern 中保留「食神格」主名、从格作为附注。

### E. 概念差异：古法「用神」≠ v3「喜用五行」

`yong_shen_elements` 5/5 一致的原因是：这 5 例原文明确「刃用官杀」，而 v3 对身强的阳刃/月劫格扶抑基线
正是 primary=[官杀]，方向吻合。这只是**基线层面**的巧合式一致，不能推断 v3 喜用体系整体符合古法：

- 古法用神 = 月令格神（十神），例如 `lu-muhuo` 建禄用伤食、`yin-wang` 印多用财；
- v3 对身强的建禄/月劫格一律给 primary=[官杀]（`lu-muhuo` 身强 → primary=[金]，而古法「建禄用伤食泄秀」→ 火），
  这类差异因概念不同未断言，但应作为引擎改进方向记录。

## 5. 建议（按可落地优先级）

1. **先修成败聚合语义**（影响 54 例）：bad 项不直接改变 status，改为「good 为主 + bad 扣层」；
   「成中有败」仅在成格条件成立且带忌时输出，`month_damage` 之「合」不计败（合待冲、冲可解）。
2. **取格优先级改造**（影响 7 例）：月令本气为格神时（官杀财印食伤，且本气当令或得势），即使不透也优先取本气；
   中气/余气透干仅在本气不透**且**本气不成格时使用；「透干」限定在月令藏干范围内，
   比肩/劫财透干只在月令本气为比劫（建禄/羊刃）时归禄刃，不得跨格套用。
3. **偏印顺逆显式配置**（影响 5 例）：在 `SHUN_NI` 与文档中声明采用「底本（枭顺用）」还是「旧版（枭逆用）」，
   并提供开关；当前 v3=旧版口径，命理文档应同步写明。
4. **从格门槛提高**（影响 3 例）：食神格在「无财、印不透、官杀不显」时易被误判从儿，
   建议要求日主无根 + 无印 + 无官杀三方条件同时成立，且从格只作附注不覆盖主格。
5. **喜用层对齐古法「用神」概念**（长期）：`yong_shen()` 输出中增加「古法用神（格神+相神）」字段，
   与「扶抑喜用五行」并列，避免两个概念在报告里混用；`lu-muhuo` 类建禄用伤食的案例可作首批回归样本。

## 7. 局限

1. 宁缺毋滥：只收四柱 + 原文结论齐全者，64 例无法代表「古典命例总体」，只作**回归样本**；
2. 电子参考版（论财/食神/偏官/伤官/阳刃）非底本影印，个别字句与断语可能经后人整理，标 `confidence=中`；
3. 原文断语多含「贵/富/丞相」等结果性描述，本对照把它们映射为「成格」是解释性约定，不是原文原话；
4. 古法用神与 v3 喜用五行概念不同（§4-E），除 5 例外未做跨概念断言；
5. 本对照**不能**用作任何「准确率」证据：一致率衡量的是与文本断语的形式吻合度，不是预测效度。

### 引擎依据本集做的修正

1. **取格**：四生/四旺月改为「以月令本气为格，中余气透出者作兼格参考」；杂气月仍按本气→中气→余气透干优先；返回 `candidates[]` 透明化不同取格口径。
2. **月令损伤**：只认冲/刑/害（子平不以三合六合判成败），且 `severity=soft`——只减力，不必然破格。
3. **成败分级**：`severity=hard`（相神/破格神）才参与成败；`severity=soft`（旺衰/月令冲刑害）只作隐忧；救应达透干/月令本气（rank≥2）视为「病解」。
4. **相神到位**：相神党透干或临月令即记 `xiangshen_<党>` 为成格条件（子平「成败以相神为要」）。
5. **顺逆用**：印格不分正偏皆顺用（修正此前把偏印格标为逆用的错误）。

### 剩余 21 处差异的性质（已知、不强行对齐）
