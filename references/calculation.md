# 排盘规则与精度说明

本文件是 `scripts/bazi.py` 的计算约定与可复算参数。改脚本前先读这里；核对结果也按这里的手算公式。

## 1. 四柱的边界

| 柱 | 边界 | 说明 |
|---|---|---|
| 年柱 | **立春交节时刻** | 不是元旦，也不是正月初一。立春前属上一年干支 |
| 月柱 | **十二「节」交节时刻** | 立春→寅月、惊蛰→卯、清明→辰、立夏→巳、芒种→午、小暑→未、立秋→申、白露→酉、寒露→戌、立冬→亥、大雪→子、小寒→丑 |
| 日柱 | 连续干支，按儒略日推算 | 以 2000-01-07 = **甲子日** 为锚点；日界为 00:00（晚子时流派见下） |
| 时柱 | 每两小时一个地支 | 23–01 子、01–03 丑、03–05 寅……21–23 亥 |

节气时刻由内置历法内核（寿星天文历系）计算，不是查表近似。脚本输出「前一节/后一节」时刻，便于核对边界。

## 2. 可手算的公式

**儒略日（Gregorian）**

```
a = (14 - month) // 12
y = year + 4800 - a
m = month + 12a - 3
JDN = day + (153m + 2)//5 + 365y + y//4 - y//100 + y//400 - 32045
```

**日柱**（JDN 取该公历日的儒略日数）：

```
i = (JDN + 49) mod 60      # 0 = 甲子
天干 = 甲乙丙丁戊己庚辛壬癸[i mod 10]
地支 = 子丑寅卯辰巳午未申酉戌亥[i mod 12]
```

校验：2000-01-01 → JDN 2451545 → i=54 → 戊午；2000-01-07 → 甲子；1949-10-01 → 甲子。

**年柱**（Y 为立春界内的公历年）：

```
i = (Y - 4) mod 60          # 1984 = 甲子
```

**月柱**：月支由节气定；月干用五虎遁：

```
月干 = (年干序号 mod 5 * 2 + 2 + (月序 - 1)) mod 10
# 月序：寅=1, 卯=2, … 丑=12；年干序号：甲=0
```

**时柱**：五鼠遁：

```
时干 = (日干序号 mod 5 * 2 + 时支序号) mod 10
# 时支序号：子=0 … 亥=11
```

## 3. 晚子时（23:00–23:59）

子时跨日，两种流派：

- `--sect 2`（默认）：**日柱不换日**（仍算当天），时干按**次日日干**起五鼠遁。
  这是「夜子时」通行的排法，也是许多排盘软件默认值。
- `--sect 1`：**23:00 起日柱即换次日**，时干按次日日干起。

两种流派在 23:00–23:59 出生时结论会不同。遇到用例子时出生时间落在该区间，要在答复中说明采用的流派，并提示另一种流派的结果。

## 4. 时区、夏令时与真太阳时

脚本输入的是**记录的钟表时间**：

1. 用 IANA 时区（默认 `Asia/Shanghai`）换算 UTC；
2. 减去该时刻的夏令时偏移，得到**标准时**（八字用标准时，不用夏令时钟表时间）；
3. 若加 `--true-solar-time --longitude`，改用**真太阳时**：

```
地方平太阳时 LMT = UTC + 经度/15 小时
真太阳时 TST = LMT + 均时差 EoT
```

**关键：两个时间标尺**

内置历法的节气表固定按北京时间（UTC+8）解释，因此必须按用途分开：

| 判定对象 | 使用的时间标尺 |
|---|---|
| 年柱、月柱 | 出生瞬间折算到 **UTC+8** 的钟表时间 |
| 日柱、时柱 | 出生地实际采用的**本地时间**（标准时，或真太阳时） |
| 大运方向、起运 | 年柱（UTC+8 标尺）+ 出生瞬间到节气的**绝对时长** |

境内出生（UTC+8）时两者相同；境外出生或使用真太阳时时两者不同。
早期版本把本地时间直接当作 UTC+8 去比较节气，导致交节附近年/月柱判错（大运方向也随之错），
现已修正，并有回归用例覆盖纽约、东京、乌鲁木齐（真太阳时）的交节边界。

均时差用 NOAA 拟合式（1800–2100 内约 ±0.5 分钟）：

```
γ = 2π/365 × (DOY − 1 + (hour−12)/24 + minute/1440 + second/86400)
EoT(分钟) = 229.18 × [0.000075 + 0.001868cosγ − 0.032077sinγ
                    − 0.014615cos2γ − 0.040849sin2γ]
```

中国 1986–1991 年夏令时（IANA `Asia/Shanghai`，以下为钟表日期；开始当日 02:00 标准时拨快至 03:00）：

| 年份 | 开始（钟表日） | 结束（钟表日） |
|---|---|---|
| 1986 | 05-04 | 09-14 |
| 1987 | 04-12 | 09-13 |
| 1988 | 04-17 | 09-11 |
| 1989 | 04-16 | 09-17 |
| 1990 | 04-15 | 09-16 |
| 1991 | 04-14 | 09-15 |

脚本不依赖此表，而是直接用 IANA 时区数据（随运行时 Python 的 tzdata），上表仅用于人工核对。

示例：1990-06-15 12:00（钟表）→ 标准时 11:00；经度 116.4° 的真太阳时约 10:45:39。
境外示例：2024-02-04 12:00 纽约（EST）→ UTC 17:00 → UTC+8 次日 01:00，已过立春，故年柱为甲辰、月柱丙寅。

## 5. 大运与起运

- **顺逆**：阳年男、阴年女顺行；阴年男、阳年女逆行（阳年 = 年干为甲丙戊庚壬）。
- **起运**：从出生时刻到下一个节（顺行）或上一个节（逆行）的时长换算。
  - `--qiyun-sect 1`：3 天 = 1 年，1 天 = 4 个月，1 时辰 = 10 天（传统法）。
  - `--qiyun-sect 2`（默认）：按分钟连续换算（4320 分钟 = 3 天 = 1 年），更细。
- **交运**：`起运时刻 + 10n 年` 为第 n 步大运的交运时刻；干支由月柱顺/逆推。起运/交运时刻按北京时间（UTC+8）表示。
- **流年**：以立春为界；流年干支 = `(Y − 4) mod 60`。流年表按公历年列出，立春前出生者该公历年仍属上一年。
- **流年与大运互动**（脚本自动计算，见输出「流年要点」）：
  - **岁运并临**：流年干支 = 大运干支；
  - **伏吟**：流年干支与某柱（或大运）完全相同；
  - **反吟（天克地冲）**：流年与该柱天干相冲、地支相冲；
  - 其余：天干合/冲、地支六合/六冲/六害/相破/自刑/子卯刑、**地支半合**（申子、子辰、寅午、午戌、巳酉、丑酉、亥卯、卯未）。

## 6. 精度与验证

| 项目 | 实现 | 实测/说明 |
|---|---|---|
| 节气时刻 | 寿星天文历系内核 | 对照外部历书：2024 立春官方 16:26:53，本引擎 16:27:07（+14 s）；2024 全年 24 节气系统性偏晚 13–16 秒；2023/2025 立春分别 +12 s、+15 s |
| 日柱 | JDN 连续干支 | 与 2000-01-07 = 甲子 锚点一致；公开历例 1949-10-01 甲子、2000-01-01 戊午 通过 |
| 年/月柱 | 交节时刻 | 2024-02-04 16:26 仍癸卯/乙丑，16:28 换甲辰/丙寅，回归通过 |
| 时柱 | 五鼠遁 | 覆盖 23:00 边界与两种流派 |
| 时区/真太阳时 | 双标尺（年/月柱用 UTC+8，日/时柱用本地/TST） | 纽约、东京、乌鲁木齐（TST）交节边界回归通过 |
| 均时差 | NOAA 拟合 | ±0.5 分钟内，只影响真太阳时，不影响日柱以外结论 |
| 起运 | 分钟法/传统法 | 两种可选，差异通常数天到数月 |

> 节气时刻的「系统性偏晚约 15 秒」来自 ΔT 模型与官方历书口径的差异：不影响任何正常出生时间的排盘结论，只对恰好在交节瞬间前后几秒出生的人有理论影响（脚本对 30 分钟内的边界一律告警）。

运行 `python tests/verify.py` 复验；42 项全部通过即视为基准未破。另有 `tests/verify_independent.py`（24 项独立公式）、`tests/verify_relations.py`（13 项关系/格局）、`tests/verify_regressions.py`（22 项时区/农历/旺衰/输入校验回归）、`tests/verify_optimizations.py`（12 项岁运并临/反吟/流月/三柱），五套合计 113 项。

**必须提示的边界情况**：

1. 出生时刻距交节 < 30 分钟 → 月/年柱可能因校正方式或出生时间误差而翻转（脚本会警告）。
2. 出生在 23:00–23:59 → 日柱随时辰流派改变。
3. 出生地在时区边界或历史上时区频繁变更的地区 → 核实时区与法令时间。
4. 时辰未知 → 时柱及其相关结论不可用。
5. 1901 年前（含 1900 年）：IANA 使用地方平太阳时（如上海 +8:05:43），与常见的“统一 +8”口径不同，需说明；脚本已按 UTC+8 标尺处理年/月柱，日/时柱仍用本地钟表时间。

## 7. 旺衰模型的参数（可调整复算）

`scripts/analysis.py` 的权重是显式常量：

```
天干权重：年/月/日/时 各 1.0
地支权重：年 1.0、月 1.6（月令最重）、日 1.2、时 1.0
藏干分配：1 个藏干 → 1.0；2 个 → 0.7/0.3；3 个 → 0.6/0.25/0.15
同党 = 比劫（同五行） + 印（生我）
异党 = 食伤（我生） + 财（我克） + 官杀（克我）
评分 = 同党占比 + 得令修正（旺+0.05/相+0.03/休−0.02/囚−0.04/死−0.06）
       + 得地 +0.03（地支藏有比劫或印）+ 得势 +0.02（天干同党 ≥ 2）
分级：≥0.62 身强；≥0.53 偏强；≥0.45 中和；≥0.37 偏弱；否则 身弱
```

这是**一个**透明模型，不是唯一答案。不同流派对月令权重、藏干比例、合化加减的处理不同；若要改变结论，改这些常量并重新跑回归即可。

## 8. 大运/流年喜忌打分与十神组合（v2，可复算）

**喜忌打分**（`analysis.flow_favorability`）：

```
基础分：天干 1.0、地支本气 1.0；藏干各 0.3（按藏干表最多计 3 个）
系数：主用 ×2.0、次用 ×1.3、喜用 ×1.0、忌神 ×-1.5、其余（中性）×0
求和后截断到 [-4, 4]
分级：≥1.6 喜；≥0.5 偏喜；>-0.5 中性；>-1.6 偏忌；≤-1.6 忌
```

每条结果附 `reasons`，列出命中的十神/五行与主用/次用标记；它只给大运、流年一个「基调」标签，不用于断具体事件。

**十神组合**（`analysis.combinations`）：

```
候选：官印相生、杀印相生、食神制杀、伤官配印、食伤生财、财官相生、
      枭神夺食、伤官见官、财星破印；另有 比劫夺财、官杀混杂、杀刃相济（计数/阳刃特例）
取级：组合两侧分别取「透干=3 / 月令本气=2 / 其他本气=1」，取两侧最大值：
      - 两侧都透干 → 透干
      - 仅一侧透干 → 半透
      - 否则（月令本气级）→ 月令
      最高 <2 的组合丢弃，避免藏支噪声；结果带 rank（1–3）并按 rank 降序返回
输出 members 按十神合并柱位（如「七杀(年柱、月柱、时柱)」）
```

组合只作结构提示：是否成格、是否破格，仍要回到旺衰、月令与破格因素复核。

## 9. 已知限制

- 不自动判断合化成功与否（合而不化是常态），只列合冲关系；天干合输出为「合X（是否化气另看）」。
- 特殊格局：v3 自动识别「从弱（从财/从杀/从儿）」与「从强（专旺）」候选并给出依据；化气格仍不自动定性，需人工判断。
- 真太阳时使用出生地经度，需用户提供；未提供时用标准时。
- 节气内核在 1900–2100 内最可靠；更早年代建议交叉核对历书。
- 月令损伤只按「地支类结构关系落在月支」计，未细分冲开墓库、合而化气等情形。
- 应期（合待冲/冲待合/填实）为提示性规则，只给「哪一年因何动」的结构提示，不给具体事件结论。

## 11. 多术数层算法（`scripts/divination.py`，可复算）

各体系互相独立，输入都取自 `chart.build()` 的确定性数据（农历、四柱、日干、时支、性别），同一输入必得同一结果。

### 11.1 小六壬


### 11.8 西洋占星 / 印度占星（`scripts/astrology.py`，纯标准库）

```
时刻：出生瞬间的绝对时刻 report.time.utc → UT；缺 utc 时回退 civil − 时区偏移，
      再回退 used（真太阳时标尺）并写 time_source 警告；儒略日 JD（Meeus 第 7 章）
      → ΔT（Espenak–Meeus 分段多项式）→ TT
黄道：黄赤交角（Meeus 22.2 含长期项）+ 章动（主项）→ 真黄道坐标
太阳：Meeus 第 25 章（几何平黄经 + 中心差 + 章动/光行时修正）
月亮：ELP-2000/82 截断（Meeus 第 47 章主导项，误差约 0.01°–0.05°）
行星：截断 VSOP87（Meeus 附录三，取主要项；水星–冥王星；秒差级截断）
      → 地心黄经 = 日心黄经 ± 180°（内行星需光行时迭代）
速度/逆行：黄经对时间的前后差商（1 日步长），速度 < 0 记逆行
宫位：Placidus（RAMC、黄赤交角、地理纬度；含极区退化到整宫制）
      纬度取 report.input.latitude；未提供按 30°N 并在 warnings/latitude_default 标注
上升/天顶：ASC = atan2(cos ε·sin RAMC, ...) 形式，MC = atan2(tan φ?…) → 标准球面公式
相位：角距 = 最小角差；orb 按「发光体/内行星/外行星/轴点」分类查表
平衡：元素（火土风水）、星座形态（基本/固定/变动）、半球（东西/南北）按行星计数
月相：距角 = 月亮黄经 − 太阳黄经 → 八相名 + 照明比例
印度盘：Lahiri 岁差近似 ayanamsa(T) → 恒星黄经 = 回归黄经 − ayanamsa；
        27 宿 = floor(恒星黄经 / 13°20′)，每宿 4 pada（3°20′/pada），宿主星固定表
```

要点：**全解析、无星历文件依赖**（因此精度约 0.01°–0.05°，不是 Swiss Ephemeris 的角秒级）；天文算得准 ≠ 星盘与人生对应成立；`--astro` 输出标注了这一点，`tests/verify_astrology.py` 用独立星历（PyEphem 测试期基准）比对。

### 11.10 跨体系融合层（`scripts/fusion.py`，v1）

```
输入：report（八字 v3 + 可选 topics/divination/ziwei；astrology/numerology 懒加载计算）
体系权重（信息量，不是效度）：八字 1.00 / 紫微 0.90 / 西洋 0.90 / 印度 0.70 /
                              数字学 0.50 / 民俗 0.40
出票：每体系把自身结构映射成 9 域（personality/career/wealth/love/health/
      family/move/study/people）上的 -2…+2 方向票，每票带一句依据文本
聚合：同体系同域多票取均值，|均值| < 0.15 视为无票；
      total = Σ(权重×体系均值)/Σ权重，clamp 到 [-2,2]
一致度：agreement = Σ权重[体系均值与 total 同号] / Σ权重（单体系时 agreement=null）
标签：agreement ≥ 0.75 →「一致」；≥ 0.55 →「多数」；> 0 →「分歧」；
      其余「对立」；无票→「证据不足」；有票但全被 0.15 阈值滤掉→「信号相抵」（读作中平）
等级：LEVEL_BANDS = 1.20 明显偏顺 / 0.55 偏顺 / 0.15 略偏顺 / -0.15 中平 /
                    -0.55 略偏吃力 / -1.20 偏吃力 / 其余 吃力
张力：consensus ∈ {分歧, 对立} 且 ≥2 体系有票 → tensions[{domain, detail}]
时机：八字聚焦年 timing.score/2 + 紫微大限 + 数字学个人年 + 民俗小六壬，加权同法
整体：agreement = 各域 agreement 均值；≥0.75 高置信 / ≥0.55 中 / 否则低
```

与 §11.6「多体系交叉参考」的区别：11.6 是**不加权**的并列摘要（各体系各说各话、标一致点/张力点）；11.10 是**加权方向聚合**（把票合成一个方向并给一致度）。两者都只描述、不预测；权重是信息量排序，不是效度排序；西洋与印度占星共享星历，权重已折价，不可当独立证据。
